# Data provenance: PyPSA-Earth defaults and what this fork adds

This repository is a fork of [PyPSA-Earth](https://github.com/pypsa-meets-earth/pypsa-earth).
Some model inputs are PyPSA-Earth's own. Others are added in this fork, mostly Taiwan data.
Every source in `pypsa_tw/data/sources.csv` has an `origin` column, and the website shows it as a
tag on each source:

| `origin` | Tag on the website | Meaning |
| --- | --- | --- |
| `pypsa-earth` | PyPSA-Earth default | Used by the standard PyPSA-Earth workflow; its data bundle, downloads or packages |
| `taiwan` | Taiwan data | A Taiwanese source added in this fork (government, Taipower, Taiwanese media) |
| `fork` | Added in this fork | Another source or a setting added in this fork (international literature, our own OSM query, assumptions) |

## Model inputs

| Input | Origin | What is used | What this fork changes |
| --- | --- | --- | --- |
| Grid | PyPSA-Earth | OpenStreetMap via earth-osm | Lines of 35 kV and above instead of 51 kV (`clean_osm_data_options.threshold_voltage`), so Taiwan's 69 kV grid is included |
| Regions | PyPSA-Earth | GADM 4.1, Marine Regions EEZ v11, clustering | 6 regions (`scenario.clusters`); isolated substations joined to the main grid |
| Demand | PyPSA-Earth + fork | GEGIS 2030 profile (SSP2-2.6, 2013 weather) | `load_options.scale: 0.749` to match Taipower-system generation in 2024 |
| Weather | PyPSA-Earth | ERA5 2013, atlite | Taiwan cutout for 2013 built locally |
| Renewable potential | PyPSA-Earth + fork | Copernicus land cover, WDPA, GEBCO, PyPSA-Earth's densities | Solar, onshore and fixed offshore settings unchanged; floating offshore wind added (pathway runs) |
| Power plants today | Taiwan | Taipower unit list, Energy Administration solar approvals, news reports | `electricity.custom_powerplants: replace` replaces powerplantmatching's fleet; IRENA top-up off (`estimate_renewable_capacities.stats: false`) |
| Power plants 2030/2034 | Taiwan | MOEA supply-demand report 113年度 | New in this fork |
| Technology costs | PyPSA-Earth + fork | technology-data v0.13.2 | Overrides: geothermal investment (IRENA); derived gas with capture (NETL), hydrogen and ammonia turbines |
| Fuel and import prices | PyPSA-Earth + fork | technology-data fuel prices | Hydrogen, ammonia and synthetic fuel import prices (Hampp et al. 2023) |
| Sector demand | PyPSA-Earth + fork | UN energy statistics, PyPSA-Earth's sector data | "Other Asia" mapped to Taiwan; Taiwan growth rates; 7.2 million cars |

The website's model data page (`docs/model-data.html`, "Where the inputs come from") shows the same
table from `INPUT_OVERVIEW` in `pypsa_tw/viewer/export_model_data.py`.

## Where the files are

| Folder | Content |
| --- | --- |
| `data/` | PyPSA-Earth's data bundle and downloads (mostly not tracked). This fork adds or edits six tracked files, listed below. |
| `pypsa_tw/data/` | This fork's data: curated tables (`sources.csv`, `taiwan_*.csv`, `plant_names_zh.csv`, `taiwan_cost_benchmarks.csv`, `taipower_plant_mapping.csv`, `supplementary_units.csv`) and the builder scripts |
| `pypsa_tw/data/official/` | Downloaded official files (PDF, CSV, XLSX, JSON), each registered in `sources.csv` with its SHA-256 |
| `pypsa_tw/config/` | Taiwan configs and scenario overlays (every change to PyPSA-Earth's settings is here) |
| `resources/`, `networks/`, `results/` | Generated by the workflow (not tracked) |

### Files in `data/` added or edited by this fork

| File | Change | Built by |
| --- | --- | --- |
| `data/custom_powerplants.csv` | Taiwan's fleet today (replaces the empty upstream file) | `pypsa_tw/data/build_custom_powerplants.py` |
| `data/custom_powerplants_tw2030.csv`, `_tw2034.csv` | Planned fleets | `pypsa_tw/data/build_future_powerplants.py` |
| `data/demand/growth_factors_cagr.csv`, `efficiency_gains_cagr.csv`, `industry_growth_cagr.csv` | One Taiwan row appended to each | `pypsa_tw/data/build_sector_growth_tw.py` |

## Changes to PyPSA-Earth's code

Most edits are marked with a `Taiwan fork` comment. Against the upstream base (`git diff 91c7ca83 HEAD -- scripts/ Snakefile`):

| File | Change |
| --- | --- |
| `Snakefile` | The custom power plant file is configurable (`electricity.custom_powerplants_file`) |
| `scripts/add_electricity.py` | New nuclear at candidate sites; floating offshore wind costs; IRENA download fix |
| `scripts/build_renewable_profiles.py` | `min_depth` for floating offshore wind |
| `scripts/build_base_energy_totals.py`, `build_base_industry_totals.py` | UN "Other Asia" mapped to Taiwan |
| `scripts/prepare_urban_percent.py` | UNCTAD file id looked up (the old id no longer exists) |
| `scripts/prepare_ports.py` | Local copy of the World Port Index when the download fails (certificate error) |
| `scripts/cluster_network.py` | Retry when the shared Gurobi licence is at its use limit |
| `scripts/prepare_energy_totals.py`, `build_industry_demand.py` | Optional demand growth overrides |
| `scripts/prepare_transport_data_input.py` | Optional transport data overrides (number of cars) |
| `scripts/add_existing_baseyear.py`, `add_brownfield.py` | Myopic-chain fixes (name clashes; retiring existing plants) |
| `scripts/prepare_sector_network.py` | Biomass fix; hydrogen imports; gas with capture, hydrogen and ammonia turbines, ammonia and synthetic fuel imports |
| `scripts/solve_network.py` | Land-use fix; capacity and generation-share bounds; nuclear caps |
