# Taiwan energy system model (TEM)

An open model of Taiwan's energy system: Taiwan data and sources, scenarios and a website, built on
[PyPSA-Earth](https://github.com/pypsa-meets-earth/pypsa-earth) through the fork
[BartonChenTW/pypsa-earth](https://github.com/BartonChenTW/pypsa-earth) (branch `taiwan`).

台灣能源系統模型（TEM）：以 PyPSA-Earth 建置的開放模型，包含台灣能源資料與來源、情境模擬及網站。
只想看結果：請看網站；想自己執行模型：`bash setup.sh`，再看 [GETTING_STARTED.md](GETTING_STARTED.md)；只需要台灣資料：看 `data/`，不必安裝模型。

## Run the model in short

The model is two folders side by side: **this repository** (Taiwan configs, data, website) and the
**model fork** (PyPSA-Earth code, environment, downloads, outputs). `setup.sh` puts them together.

```bash
git clone https://github.com/BartonChenTW/taiwan-energy-model.git
cd taiwan-energy-model
bash setup.sh              # clones ../pypsa-earth at the commit in model.lock, creates the
                           # conda environment, checks the Copernicus key, dry-runs Test 1
bash setup.sh --run-test   # also runs Test 1 (one week of 2013; the first run downloads several GB)
```

On Windows, run it in Git Bash. Afterwards, `source .tem-env.sh` sets `$PY`, `$M` (model folder) and
`$C` (configs) for the commands in [GETTING_STARTED.md](GETTING_STARTED.md), which also explains each
step by hand.

## What is in this repository

| Folder | Content | Used by |
| --- | --- | --- |
| `config/` | Taiwan configs and scenario overlays for PyPSA-Earth | Model runs |
| `data/` | Taiwan data: source registry (`sources.csv`), official files (`official/`), curated tables, power plant fleet (`fleet/`), builder scripts, checks (`check_data.py`) | Model runs, data users, website |
| `sandbox/` | What-if scenarios on today's system, solved in seconds | Model users |
| `viewer/` | Exporter from model results to the website data | Website maintainers |
| `docs/` | The website (GitHub Pages); `docs/data/` is generated by `viewer/` | Everyone |
| `notes/` | [Project log](notes/log.md), [todo list](notes/todo.md), [grid & gas network data](notes/TAIWAN_GRID_DATA.md), [weather & RE potential](notes/TAIWAN_WEATHER_RE_DATA.md), 2050 pathway, [provenance](notes/DATA_PROVENANCE.md), plans | Readers who want the details |
| `setup.sh`, `paths.py`, `model.lock` | Setup; where the model folder is (`PYPSA_EARTH_DIR`, default `../pypsa-earth`); the model commit the results were made with | Model runs |

The model itself runs in the PyPSA-Earth checkout next to this folder. What the fork changes in
PyPSA-Earth: [FORK_CHANGES.md](https://github.com/BartonChenTW/pypsa-earth/blob/taiwan/FORK_CHANGES.md).
